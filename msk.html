AMAZON MSK / SEPARATE HANDS-ON SECTION

Create MSK. Connect a client. Prove each step.

Five ordered lessons teach Amazon Managed Streaming for Apache Kafka using a standalone Java sample. Learn Kafka concepts in K01–K08 first, then use these AWS labs. EKS and the full EventFlow deployment are not prerequisites.

Reading works offline. Running the exercises needs an AWS sandbox, permissions and network access. MSK, EC2 and NAT resources are billable. No cloud deployment runs automatically. The sample compiles locally; actual AWS integration remains a hands-on learner test.

What you will build

VPC: two broker subnets in different AZs
  MSK private brokers ← IAM + TLS :9098 ← SSM-managed EC2 Java client

  Java producer → learning.msk.loan-events
                      ├─ observer consumer → terminal
                      └─ mock enrichment → learning.msk.enriched-loans
                                                └─ optional bridge → SQS + DLQ

Kafka destinations are topics; SQS destinations are queues. Only the loan data and credit-score enrichment are mocked. The AWS transport and IAM connections are real when you deploy the lab.
