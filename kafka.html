KAFKA / BEGINNER TO APPLICATION PRACTICE

Learn Kafka, one working step at a time.

Start with a separate broker and two records. Build up to consumer groups, replay and the real EventFlow Java pipeline. Every lesson provides instructions, commands, a test, expected results, source references and a review exercise.

All lessons work offline for reading. Hands-on labs need Docker or the indicated AWS services. Commands are learner exercises, not tests already executed by this documentation build. No command runs automatically.

Two environments, clearly separated

Beginner practice

Dedicated kafka-learning container. Topics learning.loan-events; groups learning-accounting and learning-audit. No LocalStack, AWS credentials or accounting input needed. One broker is for learning, not a high-availability deployment.

Application practice

Existing EventFlow MSK/Kafka environment, Java source inspection and KafkaProbe on its separate eventflow.lab topic. Only the capstone submits real POC test runs. Do not reset the finance consumer groups.

How the two Kafka topics relate

Business-event producer
  → eventflow.business-events
  → Java adapter → SQS → coordinator → Step Functions
  → Java sourcing → MOCK gRPC GetData
  → eventflow.enriched-loans
  → Java activity consumers → BE/AR → DynamoDB

gRPC streams enriched loans directly into the sourcing producer. S3 stores small manifests and checkpoints. EventFlow uses ordinary Kafka clients; it does not currently use the Kafka Streams library.

Before starting

  1. Know how to open two or three terminal windows.
  2. Have Docker Desktop available for hands-on local labs; no Java installation is needed for the container CLI exercises.
  3. Use the main IDE lessons before Java debugging, and the main AWS lessons before MSK/EKS labs.
  4. Record observed results and answer each review question before moving on.
