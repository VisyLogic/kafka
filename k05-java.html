K05 · Read and debug the Java producer and consumer

EventFlow uses the Kafka Java client directly. shared/Kafka.java builds properties and serializers; producer.send returns a future; the caller waits for acknowledgement where correctness requires it. KafkaConsumer is not thread-safe for arbitrary concurrent use. The code gives each consumer a processing loop and commits only after the relevant downstream operation has completed.

When to use it

  • Connect a Java microservice to Kafka without hiding acknowledgement behavior.
  • Trace source publication and downstream commits in an IDE.
  • Separate transport retries from deterministic financial calculations.

Create through the AWS console / IDE

  1. Open application/pom.xml in IntelliJ or EventFlow.code-workspace in VS Code. Find kafka-clients, StringSerializer and StringDeserializer.
  2. Read Kafka.producer: acks=all, enable.idempotence=true, gzip compression, size limit and delivery timeout. Broker replication and min.insync.replicas still determine the fault-tolerance boundary.
  3. Read EventAdapter: it waits for SQS acceptance before committing Kafka progress. A crash after SQS acceptance and before commit may produce duplicate SQS delivery.
  4. Read SourcingService: the enriched-loan key is eventId, not loanId. Loans from one event can share a partition; a single huge event may therefore be a hot key even with many pods.
  5. Read ActivityService: it persists outcomes before committing. Its transport retry loop can block a partition on a poison envelope; bounded retries/quarantine and partition-aware polling are future hardening work.

package com.eventflow.adapter;
import com.eventflow.shared.*;
import java.time.Duration;

/** Kafka offset moves only after SQS accepts the event. Redelivery is safe downstream. */
public final class EventAdapter {
    public static void run(){
        try(var consumer=Kafka.consumer("eventflow-adapter",Kafka.EVENTS)){
            String queue=Aws.queue();
            while(true){
                var records=consumer.poll(Duration.ofSeconds(1));
                for(var record:records){
                    // Do not skip a failed record and commit later offsets in its partition.
                    while(true){try{Aws.SQS.sendMessage(b->b.queueUrl(queue).messageBody(record.value()));break;}
                        catch(Exception e){Json.log("adapter",e.toString());sleep(2000);}}
                }if(!records.isEmpty())consumer.commitSync();
            }
        }
    }
    private static void sleep(long ms){try{Thread.sleep(ms);}catch(InterruptedException e){Thread.currentThread().interrupt();throw new RuntimeException(e);}}
}
