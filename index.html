Choose your build path

Path A · console first

Create each service manually, understand the settings, and use the CLI to inspect/test it. Keep one account/region as your manual lab.

Path B · reproducible delivery

Create a clean environment from reviewed CloudFormation, publish the tested image to ECR, and deploy the workload manifests. Do not let a new stack collide with unmanaged console resources.

What you should be able to demonstrate

  1. Explain the purpose, ownership and failure boundary of every service.
  2. Create and test each component through at least one method; inspect it through the other.
  3. Debug Java in IntelliJ or VS Code and trace a request across both Kafka topics.
  4. Reconcile distinct loans, BE/AR counts, balanced postings and workflow completion.
  5. Review a change set, promote an image digest and recover work without deleting evidence.
Evidence boundary: the small LocalStack MSK POOL/LOAN tests pass. AWS deployment, IAM-authenticated Kafka, Kubernetes scaling and large-load behavior are separate labs, not pre-certified results.
