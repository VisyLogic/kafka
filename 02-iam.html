02 · IAM roles, permissions and pod identity

IAM answers who can do what. The operator creates infrastructure; the workflow role belongs to Step Functions; the node role belongs to EC2; the application role is obtained by EKS pods. Never copy LocalStack test keys into AWS or bake credentials into an image.

When to use it

  • Use roles for temporary workload credentials and cross-service access.
  • Use IAM Identity Center for developer sessions and OIDC for CI deployment.
  • Separate console, adapter, sourcing and accounting permissions in the hardening exercise; the starter platform template uses one resource-scoped teaching application role.

Create through the AWS console / IDE

  1. IAM → Roles → Create role → AWS service → EKS → EKS cluster. Name it EventFlowClusterRole and attach AmazonEKSClusterPolicy.
  2. Create an EC2-trusted EventFlowNodeRole. Attach AmazonEKSWorkerNodePolicy, AmazonEC2ContainerRegistryPullOnly, and the teaching CNI policy AmazonEKS_CNI_Policy. A dedicated CNI role is the enterprise refinement.
  3. Create EventFlowWorkflowRole with the states.amazonaws.com trust policy. Activity workers perform work themselves, so this minimal Activity workflow role needs no broad service-invocation policy.
  4. Create an application role trusted by pods.eks.amazonaws.com for sts:AssumeRole and sts:TagSession. Attach the resource-scoped policy described in platform.yaml, replacing account/region/bucket values.
  5. After the cluster and Pod Identity agent exist, EKS → cluster → Access → Pod Identity associations → Create. Associate namespace eventflow and service account eventflow with that role.
  6. Use separate identities for deployment and runtime. Audit CloudTrail rather than placing secret keys in Java configuration.

Create or inspect through CLI

Choose this as an alternative provisioning path; do not create duplicate named resources. Commands are examples for a sandbox and require replacing placeholders. CloudShell examples use Bash; Windows-specific commands are labelled.

Test this component before continuing

Run aws iam get-role --role-name EventFlowWorkflowRole and inspect the trust principal. Later, verify the Pod Identity association and call an allowed AWS operation from a pod. A trust relationship alone does not grant S3, DynamoDB or Kafka access.

Exit criterion

Roles have the correct service principals. Java uses the default credential chain in AWS. No credentials are stored in the repository, GUI or container image.

package com.eventflow.shared;

import java.net.URI;
import java.time.Duration;
import software.amazon.awssdk.auth.credentials.*;
import software.amazon.awssdk.regions.Region;
import software.amazon.awssdk.core.client.config.ClientOverrideConfiguration;
import software.amazon.awssdk.http.urlconnection.UrlConnectionHttpClient;
import software.amazon.awssdk.services.dynamodb.DynamoDbClient;
import software.amazon.awssdk.services.s3.S3Client;
import software.amazon.awssdk.services.sqs.SqsClient;
import software.amazon.awssdk.services.sfn.SfnClient;

public final class Aws {
    private static final Region REGION = Region.of(Json.env("AWS_REGION","us-east-1"));
    private static final boolean LOCAL = !Json.env("AWS_ENDPOINT_URL", "").isBlank();
    private static final URI ENDPOINT = URI.create(Json.env("AWS_ENDPOINT_URL","https://localhost"));
    private static final AwsCredentialsProvider CREDS = LOCAL
        ? StaticCredentialsProvider.create(AwsBasicCredentials.create("test","test"))
        : DefaultCredentialsProvider.create();
    private static final ClientOverrideConfiguration TIMEOUT = ClientOverrideConfiguration.builder()
        .apiCallTimeout(Duration.ofSeconds(85)).apiCallAttemptTimeout(Duration.ofSeconds(75)).build();
    public static final DynamoDbClient DB = db();
    public static final S3Client S3 = s3();
    public static final SqsClient SQS = sqs();
    public static final SfnClient SFN = sfn();
    public static final String TABLE=Json.env("TABLE_NAME","eventflow-data");
    public static final String BUCKET=Json.env("BUCKET_NAME","eventflow-artifacts-local");
    public static final String PREFIX="arn:aws:states:"+REGION+":"+Json.env("AWS_ACCOUNT_ID","000000000000")+":";
    private static DynamoDbClient db(){var b=DynamoDbClient.builder().region(REGION).credentialsProvider(CREDS).overrideConfiguration(TIMEOUT).httpClientBuilder(UrlConnectionHttpClient.builder());if(LOCAL)b.endpointOverride(ENDPOINT);return b.build();}
    private static S3Client s3(){var b=S3Client.builder().region(REGION).credentialsProvider(CREDS).overrideConfiguration(TIMEOUT).forcePathStyle(LOCAL).httpClientBuilder(UrlConnectionHttpClient.builder());if(LOCAL)b.endpointOverride(ENDPOINT);return b.build();}
    private static SqsClient sqs(){var b=SqsClient.builder().region(REGION).credentialsProvider(CREDS).overrideConfiguration(TIMEOUT).httpClientBuilder(UrlConnectionHttpClient.builder());if(LOCAL)b.endpointOverride(ENDPOINT);return b.build();}
    private static SfnClient sfn(){var b=SfnClient.builder().region(REGION).credentialsProvider(CREDS).overrideConfiguration(TIMEOUT).httpClientBuilder(UrlConnectionHttpClient.builder().socketTimeout(Duration.ofSeconds(70)));if(LOCAL)b.endpointOverride(ENDPOINT);return b.build();}
    public static String queue(){return SQS.getQueueUrl(b->b.queueName("eventflow-ingress")).queueUrl();}
}

  • Recovery action and how you checked the business invariants.
